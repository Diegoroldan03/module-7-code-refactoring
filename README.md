# Module 7: Python Code Refactoring

This project improves an existing Python script through clearer names, function documentation, and simpler code while preserving its original functionality.

## What the Program Does

The program doubles even numbers and triples odd numbers, then converts words longer than five characters to uppercase and the remaining words to lowercase.

## Requirements

Python 3 is required and no additional packages are needed.

## How to Run

Download undocumented_script.py and open a terminal in the folder containing the file, then run:

```powershell
python undocumented_script.py
```

## Expected Output

```text
Processed Numbers: [3, 4, 9, 8, 15, 12, 21]
Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
```

## Project Files

- code_refactoring_starter.py — Original script provided by the instructor.
- undocumented_script.py — Refactored and documented version.
- CODE_REVIEW.md — Initial observations and final review.
- DECISIONS.md — Explanation of the refactoring decisions.
